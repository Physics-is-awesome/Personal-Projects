\section{Beginning Kerr Spacetime*}

One can define the difference between rotation types to be given by the horizon function $\Delta = r^2 -2Mr + a^2$(this is in geometrized units)

The kerr metric does not fail at $r=0$ like the Schwarzchild solution does. Though it adds the two horizons and the ring singularity.
