This theorem is valid for dynamics $\theta ' = \theta \alpha(r)$, provided $\alpha$ is irrational.

\[
\delta f(\theta) = \sum_{k=1}^\infty \left[a_k e^{ik\theta} + a^{*}_ke^{-ik\theta}  \right]
  \]

  assuming that $\abs{a_k} < \frac{a_1}{k^2}$ to eliminate discontinuous functions. Summing this we can get that the sum diverges wher $k \alpha = 2 \pi m$. The sum will converge provided that
\[
\abs{\frac{\alpha}{2 \pi} - \frac{m}{n} > \frac{\epsilon}{n^3}}
