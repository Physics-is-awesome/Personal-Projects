\subsection{General idea}

To test the effects of differing modified GR theories. I would like to create N-body post-Newtonian codes. From here I would like to simulate a simple version of the solar system.

I would like to test:
\begin{itemize}
  \item f(R)
  \item Higher dimensional Brans-Dicke gravity
  \item Kaluza-Klein Compact dimensions with that are large enough to effect the solar system
\end{itemize}
